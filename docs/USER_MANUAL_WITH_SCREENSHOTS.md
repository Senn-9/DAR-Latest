## 12. Basic Troubleshooting

### Cannot Log In
- Recheck username and password.
- Ask Admin to verify your account.

### Missing Buttons
- Your role may not have permission.
- Re-login and ask Admin to confirm role access.

### PR Not Saving
- Fill required fields.
- Check number fields.
- Retry after page refresh.

### Upload Failure
- Check file type and size.
- Confirm storage is enabled by Admin.

### Slow System
- Refresh page.
- Check internet connection.
- Try again later.
